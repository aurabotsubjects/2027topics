# 2027 Topics (Years 5–6)

One folder, one GitHub repository, three teacher-run presentation apps. `index.html` is the landing page; each topic opens from it.

| Order | Topic | App | Folder |
|---|---|---|---|
| 1st | Maya & Aztecs | The Fifth Codex | `maya-aztecs/` |
| 2nd | Hakatere | The Braided Map | `hakatere/` |
| 3rd | Persia | The Royal Road | `persia/` |

Each folder is a complete app (its own `index.html`, `css`, `js`, `data`, `assets`, README and blueprint), so all the existing instructions in each README still apply. The only change to each app is a **‹ 2027 Topics** button at the start of its top bar, which returns to this landing page.

## Open it
- **On your Mac:** double-click `index.html` in this folder.
- **Online:** put the whole `2027topics` folder in one GitHub repository (the folder's contents at the repo root), then turn on GitHub Pages or connect it to Netlify. There is no build step. The landing page will be the site's home page; the topics are at `/maya-aztecs/`, `/hakatere/` and `/persia/`.

## Notes
- Each topic saves its own progress, teams and class list in the browser under a separate key (`fc5:`, `bm1:`, `rr1:`), so they never clash, even on one web address. Settings, class lists and backups are **per topic**.
- The original folders (`maya&aztecs`, `hakatere`, `PersiaNew`) were copied, not moved, and are untouched.
- Paths inside each app are relative, so a topic folder can be renamed or moved as long as it stays one level below `index.html`.
