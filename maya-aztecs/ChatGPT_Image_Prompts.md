# The Fifth Codex: ChatGPT Image Prompts

The app already looks finished without any images, because every scene is drawn in code. Images you make in ChatGPT are an optional upgrade.

## How to use these images
1. Paste the **STYLE LOCK** first, then add the prompt for the image you want.
2. Save the image as **WebP** (or PNG, then convert it) using the **exact file name** shown in this file.
3. Put the file in `maya&aztecs/assets/img/`. The app finds it automatically and fades it in. If a file is missing, the app uses its built-in art instead, so nothing breaks.

> **Ready now (Week 1):** the five character portraits. They replace the paper portraits on every Field Transmission slide.
> **For later phases:** the hero scenes and artefact cards. Make them whenever you like; they'll be wired in as each week is built.

## STYLE LOCK (paste this first, every time)
> Sophisticated layered cut-paper diorama illustration, museum-exhibition quality, not childish. Five to seven physical paper layers with soft, realistic cast shadows between them, giving real depth. Textured handmade amate bark paper and matte card with visible fibres and subtly torn edges. Palette strictly limited to: obsidian black #14110F, warm amate cream #E9DCC0, aged paper tan #C9A97A, cacao brown #5A3825, jade green #1F7A5A, Maya blue #2E9FB0, deep quetzal green #0F5E47, cochineal red #B3262E, ochre gold #D9A23A, copper #C46A3A. Mesoamerican geometric motifs (stepped frets, chevrons) used as framing only. Cinematic lighting from one side, gentle atmospheric haze between layers. Precise, elegant, editorial. No text, no letters, no logos, no watermarks. No cartoon faces, no googly eyes, no thick black outlines, no glossy 3D plastic look. Respectful and historically grounded.

### Rules for all images
- No photos or likenesses of real people. Every character is fictional.
- No images presented as real photographs of real artefacts. Label them as reconstructions.
- No violence or gore, and no faces of deities used as decoration.
- Don't copy a specific museum's photograph.
